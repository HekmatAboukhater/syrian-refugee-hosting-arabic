# Translation glossary · مسرد الترجمة

The Arabic note translates the accompanying English research note. Equations, units, country scope and numerical findings are preserved. The choices below keep related statistical concepts distinct.

| English term | المقابل العربي | Translation decision |
| --- | --- | --- |
| Refugee hosting | استضافة اللاجئين | Refers to presence and protection in the destination. |
| Refugee stock | عدد اللاجئين القائم في تاريخ معيّن | Avoids the literal «مخزون اللاجئين», which sounds unnatural when referring to people. |
| Annual inflow | عدد الوافدين خلال السنة | A flow measured over a period. |
| Year-end stock | عدد اللاجئين في نهاية السنة | The time reference used by the UNHCR series. |
| Pending asylum-seekers | طالبو اللجوء الذين ما زالت طلباتهم قيد النظر | Preserves the pending-decision condition. |
| Resident population | السكان المقيمون | The denominator includes residents of different citizenships. |
| Numerator | البسط | The refugee count in the population ratio. |
| Denominator | المقام | The resident-population estimate in the population ratio. |
| Population normalisation | احتساب العدد نسبةً إلى السكان | Explains the operation rather than using a literal «تطبيع» that can be ambiguous. |
| Refugees per 1,000 residents | عدد اللاجئين لكل ألف مقيم | Retains the multiplier and the population basis. |
| Hosting intensity | كثافة الاستضافة | Used for a population ratio, without attaching a moral judgement to the number. |
| Country-year observation | مشاهدة لدولة في سنة معيّنة | One row in the selected panel. |
| Panel data | بيانات مقطعية زمنية | Repeated country observations across years. |
| Share | الحصة من الإجمالي | A count divided by the relevant total. |
| Percentage point | نقطة مئوية | A difference between percentages. |
| Concentration | التركّز | Distribution across destinations. |
| Herfindahl–Hirschman index | مؤشر هيرفندال–هيرشمان | Sum of squared destination shares. |
| Effective number of destinations | عدد الوجهات المتساوية الحجم المكافئ للتوزيع | Explains the reciprocal-index interpretation. |
| Sensitivity check | فحص الحساسية | Here, broadening the numerator to include pending asylum-seekers. |
| Causal identification | تحديد الأثر السببي | Requires a design connecting exposure to outcomes. |
| Naturalisation | اكتساب الجنسية | A status transition distinct from admission or arrival. |
| Reproducibility | قابلية إعادة إنتاج النتائج | Regenerating outputs from the same inputs and code. |
